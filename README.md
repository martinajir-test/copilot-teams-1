# copilot-teams-1

A simple test repository demonstrating basic testing infrastructure.

## Features

- Basic utility functions (add, multiply, greet)
- Jest testing framework
- Test coverage reporting
- CI-ready test scripts

## Installation

```bash
npm install
```

## Running Tests

```bash
# Run all tests
npm test

# Run tests in watch mode
npm run test:watch

# Run tests with coverage report
npm run test:coverage
```

## Project Structure

- `index.js` - Main utility functions
- `index.test.js` - Test cases for utility functions
- `jest.config.js` - Jest configuration
- `package.json` - Project dependencies and scripts
