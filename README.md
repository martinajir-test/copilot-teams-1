# copilot-teams-1

A simple JavaScript project with test infrastructure.

## Features

- Basic math functions (add, subtract)
- Jest testing framework

## Installation

```bash
npm install
```

## Running Tests

```bash
npm test
```

## Usage

```javascript
const { add, subtract } = require('./index');

console.log(add(2, 3));      // 5
console.log(subtract(5, 3)); // 2
```
