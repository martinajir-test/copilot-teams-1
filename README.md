# Copilot Teams Test Repository

A test repository for exploring and demonstrating GitHub Copilot for Teams functionality.

## 📋 About

This repository serves as a testing ground for GitHub Copilot Teams features, allowing teams to experiment with AI-powered coding assistance in a collaborative environment.

## 🚀 Getting Started

This is a minimal test repository. To use it:

1. **Clone the repository**
   ```bash
   git clone https://github.com/martinajir-test/copilot-teams-1.git
   cd copilot-teams-1
   ```

2. **Explore Copilot Features**
   - Open the repository in your preferred IDE with GitHub Copilot extension
   - Try creating new files and let Copilot suggest code completions
   - Experiment with Copilot Chat for code explanations and improvements
