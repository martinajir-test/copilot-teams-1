# copilot-teams-1

## User Preferences Dialog Demo

A simple web application demonstrating a user preferences dialog with the following features:

### Features
- **User Preferences Dialog**: A modal dialog for managing user preferences
- **Preference Options**:
  - Theme selection (Light, Dark, Auto)
  - Notifications toggle (Enabled, Disabled)
  - Language selection (English, Spanish, French, German)
- **Local Storage**: Preferences are saved to browser's local storage
- **Responsive Design**: Works on desktop and mobile devices
- **Keyboard Support**: Press Escape to close the dialog

### How to Use
1. Open `index.html` in a web browser
2. Click "Open Preferences" button to view the preferences dialog
3. Select your preferred settings
4. Click "Save Preferences" to save your choices
5. Your preferences will be displayed on the main page and persisted across sessions

### Files
- `index.html` - Main HTML structure
- `styles.css` - Styling for the application and dialog
- `script.js` - JavaScript functionality for dialog and preferences management
