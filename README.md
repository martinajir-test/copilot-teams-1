# copilot-teams-1

A simple user profile management application that lets you view and edit your profile information.

## Features

- View your profile with name, email, bio, and avatar initials
- Edit and save profile data (persisted in localStorage)
- Client-side email validation
- Toast notifications for save confirmations

## Usage

Open `index.html` in a browser to use the application.

## Development

Install dependencies and run tests:

```bash
npm install
npm test
```
