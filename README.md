# copilot-teams-1

A simple interactive dashboard application.

## Features

- **Personalized Greeting**: Enter your name to receive a time-based greeting (morning/afternoon/evening)
- **Visit Counter**: Tracks the number of times you've visited the dashboard (stored in browser localStorage)
- **Quick Stats Display**: Shows sample statistics with interactive cards

## Usage

Simply open `index.html` in your web browser to view the dashboard.

## Files

- `index.html` - Main dashboard HTML structure
- `style.css` - Styling and layout
- `script.js` - Interactive features and functionality
