# copilot-teams-1

## Simple Calculator App

A simple, functional calculator app built with HTML, CSS, and JavaScript.

### Features
- Basic arithmetic operations: addition (+), subtraction (-), multiplication (*), division (/)
- Decimal number support
- Clear (C) and delete (←) functions
- Division by zero protection
- Clean, modern UI with responsive design

### How to Use
1. Open `index.html` in any modern web browser
2. Click number buttons to input numbers
3. Click operator buttons (+, -, *, /) to perform operations
4. Click = to see the result
5. Click C to clear the calculator
6. Click ← to delete the last digit

### Files
- `index.html` - Main HTML structure
- `calculator.css` - Styling and layout
- `calculator.js` - Calculator logic and functionality
