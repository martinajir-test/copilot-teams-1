# copilot-teams-1

## Description

Bienvenue dans le projet copilot-teams-1. Ce dépôt fait partie d'une initiative collaborative utilisant GitHub Copilot pour améliorer le développement en équipe.

## À propos

Ce projet démontre l'utilisation de GitHub Copilot dans un environnement de développement collaboratif, permettant aux équipes de travailler plus efficacement ensemble.

## Installation

Pour utiliser ce projet, clonez le dépôt sur votre machine locale :

```bash
git clone https://github.com/martinajir-test/copilot-teams-1.git
cd copilot-teams-1
```
